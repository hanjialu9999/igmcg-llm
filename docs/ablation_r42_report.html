核心发现

基于 800 序列完整验证集的三模式对比

Controller 是质量核心

开启 Controller 后 TF PPL 从 970.1 → 106.4（9.1× 改善）。关闭 Controller 时三种解码模式完全一致，模型退化为普通前馈网络。

Direction 提升 TF 但破坏增量解码

Direction 使 TF PPL 从 199.4 → 106.4（降 47%），但 Incremental PPL 飙升至 37,265，KV-Cache 增量解码完全不可用。

CMB 修复增量解码一致性

Char-Merge-Buffer 在 Direction=Off 时使 Incremental PPL 从 324.7 → 190.3，与 Prefix 完全对齐（差值 < 0.001），实现三模式一致。

完整模型存在推理矛盾

完整模型（Ctrl+Dir+CMB）TF 最优但 Incremental 崩溃，无法用于实际部署。推荐部署配置：Ctrl=On, Dir=Off, CMB=On。
